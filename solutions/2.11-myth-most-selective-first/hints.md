## 1

Размер индекса: `SELECT pg_relation_size('orders_cs_idx') / 8192;`. Для измерений используйте приём с `BEGIN; DROP INDEX ...; EXPLAIN ...; ROLLBACK;` из условия.

## 2

В запросе both заданы обе колонки. Пара значений однозначно определяет место в индексе при любом порядке колонок. В запросе queue задан только `status`: посмотрите, сколько страниц читает каждый вариант, и сравните с размером индекса.

## 3

Запросу queue нужен индекс, который начинается со `status`. Запросу both порядок безразличен. Значит, для нагрузки из этих двух запросов первая колонка — `status`.
