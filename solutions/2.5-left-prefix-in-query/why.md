# Разбор 2.5

```sql
SELECT id, email
FROM customers
WHERE country IN ('AT', 'BE', 'BG', 'CZ', 'DE', 'DK', 'ES', 'FI', 'FR', 'HR', 'HU',
                  'IE', 'IT', 'NL', 'PL', 'PT', 'RO', 'SE', 'SI', 'SK', 'UA')
  AND last_name = 'novak' AND first_name = 'jana';
```

**Было.** `Bitmap Index Scan` с `Index Cond: ((last_name = 'novak') AND (first_name = 'jana'))`. Индекс прочитан целиком, около 170 страниц на масштабе `s`, потому что записи отсортированы сначала по стране, и Jana Novak встречается в каждой из 21 страны. Плюс около 95 страниц таблицы. Всего примерно 270.

**Стало.** `Index Cond` начинается с `country = ANY ('{AT,BE,...}')`. Для каждой страны Postgres делает отдельный короткий спуск к участку «страна + novak + jana»: 21 спуск, около 40 страниц индекса вместо 170. Таблица та же, около 95 страниц. Всего около 140.

На масштабе `s` выигрыш вдвое, потому что строки в таблице всё равно нужно прочитать. С ростом таблицы индекс растёт, а спусков по-прежнему 21: на масштабе `m` разница уже в разы.

Это ручная версия **skip scan**: перебрать значения первой колонки и сделать отдельный поиск для каждого. В PostgreSQL 18 это умеет сам планировщик, если значений первой колонки мало. В 16 и ниже — только так.

## Цена решения

Запрос верен, пока список стран полный. Появится клиент из новой страны — запрос молча его не найдёт. Поэтому это приём для ситуации «индекс менять нельзя, а надо сейчас». Правильное долгосрочное решение — индекс, который начинается с `last_name`, или переход на версию со skip scan.

Можно не хранить список в коде, а получать его из базы рекурсивным запросом (loose index scan), который делает по одному спуску на страну. Он тоже пройдёт проверку, но сложнее: попробуйте написать сами, если интересно.

## Ловушки

- **`country = ANY (ARRAY(SELECT DISTINCT country FROM customers))`.** Результат правильный, но чтобы найти уникальные страны, Postgres читает весь индекс. Получается дороже исходного запроса.
- **Неполный список стран.** Запрос быстрый, но теряет клиентов. Проверка сравнивает результат с эталоном и это поймает.
