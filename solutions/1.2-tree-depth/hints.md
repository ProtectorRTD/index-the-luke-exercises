## 1

`level` и номер корневой страницы есть в одной строке `bt_metap`. Глубина спуска на единицу больше `level`: листья тоже уровень.

## 2

Чтобы посчитать листья, нужно перебрать все страницы индекса. Их номера от 1 до `pg_relation_size / 8192 - 1`, страница 0 служебная. Для каждой вызовите `bt_page_stats` и оставьте `type = 'l'`.

## 3

Поиск одной строки по `Index Scan`: по одной странице на каждый уровень дерева плюс одна страница таблицы, где лежит строка. Для проверки:

```sql
SELECT created_at FROM orders WHERE id = 123456;
EXPLAIN (ANALYZE, BUFFERS) SELECT * FROM orders WHERE created_at = '<значение выше>';
```
