# Разбор 0.2

`GROUP BY country` раскладывает клиентов по странам, `count(*)` считает размер каждой группы, `ORDER BY ... DESC` ставит самые большие сверху, `LIMIT 5` отрезает пять.

Второй ключ сортировки (`country`) нужен для однозначности. У нескольких стран число клиентов почти одинаковое. Если бы два значения совпали, без второго ключа порядок между ними мог бы меняться от запуска к запуску. Это пригодится в модуле 9: пагинация без уникального ключа сортировки теряет и дублирует строки.
