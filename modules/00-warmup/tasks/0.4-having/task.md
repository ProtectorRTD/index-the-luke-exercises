# 0.4. Средний чек по крупным статусам

**Тип:** запросы. Проверяется только результат.

## Сценарий

Для каждого статуса заказа нужно число заказов и средняя сумма заказа. Показывать только статусы, в которых больше 20 000 заказов.

Результат: колонки `status`, `orders_count`, `avg_total`. Среднее округлить до двух знаков. Порядок строк не важен.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.4`.
