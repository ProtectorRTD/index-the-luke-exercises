# 0.11. Читаем план: ошибка оценки

**Тип:** ответы. Ничего выполнять не нужно: план уже снят, его надо прочитать.

## Запрос

```sql
SELECT c.country, count(*) AS orders_2025
FROM orders o
JOIN customers c ON c.id = o.customer_id
WHERE extract(year FROM o.created_at) = 2025
GROUP BY c.country
ORDER BY count(*) DESC
LIMIT 3;
```

Индексов, кроме первичных ключей, нет.

План снят на масштабе `s` командой `EXPLAIN (ANALYZE, BUFFERS)` и лежит в [plan.txt](plan.txt). Числа в плане фиксированы, на вашей базе они могут немного отличаться: отвечайте по файлу.

## Вопросы

Ответы впишите в `answers.yaml`. Названия узлов пишите как в плане, числа цифрами.

1. `misestimated_table`: при чтении какой таблицы (orders или customers) оценка числа строк ошиблась сильнее всего.
2. `estimated_rows`: сколько строк там ожидал планировщик.
3. `actual_rows`: сколько строк там вернулось на самом деле.
4. `aggregate_node`: каким узлом выполняется группировка.
5. `groups`: сколько групп (строк) вернула группировка.
6. `sort_method`: какой метод сортировки использован (Sort Method).
