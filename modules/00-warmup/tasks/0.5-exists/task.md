# 0.5. Австрийцы с крупными заказами

**Тип:** запросы. Проверяется только результат.

## Сценарий

Нужен список клиентов из Австрии (`country = 'AT'`), у которых есть хотя бы один заказ дороже 3000.

Результат: колонки `id`, `email`, по одной строке на клиента, сортировка по `id`.

Порядок строк проверяется.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.5`.
