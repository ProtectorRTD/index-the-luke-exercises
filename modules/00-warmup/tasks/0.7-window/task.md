# 0.7. Нарастающий итог и динамика

**Тип:** запросы. Проверяется только результат.

## Сценарий

К выручке по месяцам из задания 0.6 финансы хотят добавить:

- `running_total` — нарастающий итог с начала года;
- `change_pct` — изменение к предыдущему месяцу в процентах, округлённое до одного знака: `round(100 * (выручка - выручка_прошлого_месяца) / выручка_прошлого_месяца, 1)`. Для января предыдущего месяца нет, там должен быть `NULL`.

Результат: колонки `month`, `revenue`, `running_total`, `change_pct`. 12 строк, сортировка по месяцу.

Порядок строк проверяется.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.7`.
