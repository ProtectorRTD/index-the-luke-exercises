# 0.2. Топ-5 стран по числу клиентов

**Тип:** запросы. Проверяется только результат.

## Сценарий

Для отчёта нужны пять стран, в которых больше всего клиентов.

Результат: колонки `country`, `customers_count`. Сортировка по числу клиентов по убыванию, при равенстве — по коду страны по возрастанию. Ровно 5 строк.

Порядок строк проверяется.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.2`.
