# 0.1. Заказы в ожидании из Чехии

**Тип:** запросы. Проверяется только результат.

## Сценарий

Отдел логистики хочет знать, сколько заказов в статусе `pending` сейчас у клиентов из Чехии (`country = 'CZ'`).

Результат: одна строка, одна колонка — число заказов.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.1`.
