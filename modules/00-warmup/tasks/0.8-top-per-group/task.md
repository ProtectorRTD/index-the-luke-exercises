# 0.8. Топ-3 товара в каждой категории

**Тип:** запросы. Проверяется только результат.

## Сценарий

Для каждой категории нужны три товара, которых продали больше всего штук в 2025 году. Считаются позиции (`order_items.quantity`) из доставленных заказов (`orders.status = 'delivered'`), созданных в 2025 году.

Результат: колонки `category` (название категории), `product_id`, `product_name`, `units` (сумма штук), `rank` (1, 2, 3). При равном числе штук выше товар с меньшим `product_id`. Сортировка по названию категории, затем по `rank`. 60 строк: 20 категорий по 3 товара.

Порядок строк проверяется.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.8`.

## Какой SQL понадобится

Соединение четырёх таблиц, `GROUP BY`, `row_number() OVER (PARTITION BY ... ORDER BY ...)`, фильтр по номеру во внешнем запросе. Примеры в [cheatsheet.md](../../cheatsheet.md).
