# 0.3. Клиенты без заказов

**Тип:** запросы. Проверяется только результат.

## Сценарий

Маркетинг хочет отправить письмо клиентам, которые зарегистрировались, но ни разу ничего не заказали. Сколько таких клиентов?

Результат: одна строка, одна колонка — число клиентов.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.3`.

## Какой SQL понадобится

`NOT EXISTS (подзапрос)` или `LEFT JOIN ... WHERE ... IS NULL`. Оба способа есть в [cheatsheet.md](../../cheatsheet.md). Примеры в [cheatsheet.md](../../cheatsheet.md).
