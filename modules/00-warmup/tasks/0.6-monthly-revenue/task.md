# 0.6. Выручка по месяцам

**Тип:** запросы. Проверяется только результат.

## Сценарий

Финансы просят выручку по месяцам за 2025 год. Выручка — сумма `total` по доставленным заказам (`status = 'delivered'`). Месяц определяется по `created_at`.

Результат: колонки `month` (тип `date`, первое число месяца, например `2025-01-01`) и `revenue`. 12 строк, сортировка по месяцу.

Порядок строк проверяется.

## Что сделать

1. Напишите запрос в `solution.sql`. Пробуйте его в `lab psql`.
2. Запустите `lab check 0.6`.

## Какой SQL понадобится

`date_trunc('month', ...)`, приведение `::date`, условие на диапазон дат, `GROUP BY`, `sum`. Примеры в [cheatsheet.md](../../cheatsheet.md).
