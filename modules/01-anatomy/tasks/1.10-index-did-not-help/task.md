# 1.10. Индекс добавили, а быстрее не стало

**Уровень:** расследование. В чём причина, задание не говорит.

## Сценарий

На странице клиента есть блок «Доставленные заказы». Запрос (`query.sql`):

```sql
SELECT id, created_at, total
FROM orders
WHERE status = 'delivered' AND customer_id = 54321;
```

Месяц назад на него пожаловались, и под этот запрос добавили индекс. Его создаёт `setup.sql`:

```sql
CREATE INDEX orders_status_idx ON orders (status);
```

Быстрее не стало. Вас просят разобраться.

Ограничение: на `orders` разрешён **один** индекс, кроме первичного ключа. Запрос менять нельзя.

## Что сделать

1. `lab reset`, в `lab psql` выполните `\i modules/01-anatomy/tasks/1.10-index-did-not-help/setup.sql`.
2. Выясните, почему существующий индекс не помогает. Сформулируйте причину одной фразой, с числами.
3. Исправьте ситуацию в `solution.sql`.
4. `lab check 1.10`.

## Как проверяется

- на `orders` не больше одного индекса, кроме первичного ключа;
- в плане нет `Seq Scan` по `orders`;
- запрос читает не больше 20 страниц.
