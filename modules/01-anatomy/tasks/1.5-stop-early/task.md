# 1.5. Остановиться на первой строке

**Тип:** запросы. Индексы даны и меняться не могут, переписать нужно запрос.

## Сценарий

`setup.sql` создаёт индекс по клиенту:

```sql
CREATE INDEX orders_customer_id_idx ON orders (customer_id);
```

Перед показом бейджа «постоянный покупатель» приложение проверяет, есть ли у клиента хоть один доставленный заказ. Запрос в `query.sql`:

```sql
SELECT count(*) > 0 AS has_delivered
FROM orders
WHERE customer_id = 17 AND status = 'delivered';
```

Клиент 17 — оптовик, у него сотни заказов. Чтобы ответить «да», Postgres находит и проверяет их все.

## Что сделать

1. `lab reset`, в `lab psql` выполните `\i modules/01-anatomy/tasks/1.5-stop-early/setup.sql` и посмотрите план исходного запроса. Сколько строк и страниц он читает?
2. Перепишите запрос в `solution.sql` так, чтобы чтение прекращалось на первой подходящей строке. Результат должен остаться тем же: одна строка с одной колонкой `true` или `false`.
3. `lab check 1.5`.

## Как проверяется

- результат совпадает с эталоном;
- запрос трогает не больше 10 страниц.

После PASS ответьте себе: что вернул бы ваш запрос для клиента, у которого нет ни одного доставленного заказа? А вариант с `LIMIT 1`?
