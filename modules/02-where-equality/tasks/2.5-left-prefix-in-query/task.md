# 2.5. Левый префикс со стороны запроса

**Тип:** запросы. Индексы даны и меняться не могут, переписать нужно запрос.

## Сценарий

Для поиска клиентов по стране давно есть индекс, его создаёт `setup.sql`:

```sql
CREATE INDEX customers_country_name_idx ON customers (country, last_name, first_name);
```

Теперь операторам нужен поиск по имени и фамилии без страны (`query.sql`):

```sql
SELECT id, email
FROM customers
WHERE last_name = 'novak' AND first_name = 'jana';
```

Новый индекс добавить нельзя: таблица большая, и DBA против ещё одного индекса. Но стран в базе немного, и `country` у каждого клиента заполнена.

## Что сделать

1. Заполните `prediction.md`.
2. `lab reset`, в `lab psql` выполните `\i modules/02-where-equality/tasks/2.5-left-prefix-in-query/setup.sql` и посмотрите план. Сравните `Buffers` с размером индекса.
3. Перепишите запрос в `solution.sql` так, чтобы условие на **первую** колонку индекса появилось в `Index Cond`, а результат остался тем же.
4. `lab check 2.5`.

## Как проверяется

- результат совпадает с эталоном, порядок строк не важен;
- все три колонки индекса, `country`, `last_name` и `first_name`, стоят в `Index Cond`;
- запрос трогает не больше 220 страниц на масштабе `s` (на `m` — не больше 1 000).
