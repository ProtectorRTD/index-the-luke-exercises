# 2.1. Составной индекс

**Тип:** индексы. Запрос менять нельзя.

## Сценарий

На странице клиента есть вкладка «Отменённые заказы». Запрос в `query.sql`:

```sql
SELECT id, created_at, total
FROM orders
WHERE customer_id = 17 AND status = 'cancelled';
```

Клиент 17 — оптовик: у него около 500 заказов, отменённых среди них около десятка.

## Что сделать

1. Заполните `prediction.md`.
2. Посмотрите исходный план в `lab psql`.
3. В `solution.sql` создайте индекс, после которого база читает только отменённые заказы клиента и ничего не выбрасывает фильтром.
4. `lab check 2.1`.

## Как проверяется

- создан ровно один новый индекс;
- обе колонки, `customer_id` и `status`, стоят в `Index Cond`;
- фильтром не отброшено ни одной строки;
- запрос трогает не больше 30 страниц.

После PASS попробуйте в psql индекс только по `customer_id` и посмотрите на `Rows Removed by Filter`.
